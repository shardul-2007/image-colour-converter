ImageManager Class

Encapsulates the pristine original image data and provides bounds-checked metadata inspection.

ColourProcessor Class

Applies non-destructive mathematical transforms (BT.601 grayscale, inversion, channel isolation/scaling).

OutputManager Class

Validates file formats and performs image serialization for PNG/JPEG export without data corruption.

ImageConverterApp Class

Coordinates system state, dispatches user actions, and manages the interactive Pixel Inspector HUD.
